# Important — Fabric 1.21.11

## Build online with GitHub Actions

1. Create a GitHub repository and upload the contents of this folder (including `.github/workflows/build.yml`).
2. Open the repository's **Actions** tab.
3. Select **Build Important Fabric Mod** and click **Run workflow**. A push to the repository also starts a build.
4. When the run finishes, open it and download the artifact named `important-fabric-1.21.11`.

The artifact contains the JAR files produced by Gradle. A successful build is not guaranteed until GitHub Actions completes without errors.
